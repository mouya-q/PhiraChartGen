# AI 数据使用声明

## 默认状态

AI 增强默认关闭. 只有在设置页打开开关并明确同意后才会生效

## 会发送什么

每次生成发送一次请求 (失败时按你设置的次数重试), 内容为:

- 曲速 (BPM, 保留一位小数)
- 按乐句 (8 拍为一个乐句) 统计: 乐句序号, 相对能量 (相对全曲高潮的比值), 起音数量
- 一段固定的设计说明 (判定线手法库与输出格式), 其中不包含你的任何数据

示例:

```
{"bpm":128.0,"phrases":[{"i":0,"e":0.21,"o":3},{"i":1,"e":0.35,"o":9}, ...]}
```

## 不会发送什么

- 音频内容或其任何片段
- 文件名, 路径, 曲名, 艺术家, 封面
- 设备信息, 账号信息, 位置

## 发送到哪里

你在设置中填写的接口地址, 使用 OpenAI 兼容的 chat completions 接口. 请求由该服务方处理, 数据保留与使用政策由其决定, 请自行了解并确认可以接受

## 模型返回什么, 如何使用

模型按乐句返回编排建议, 每项都是可选的:

- `style`: 主线风格, 只能是 STEADY, PULSE, SPLIT, SPIN 之一
- `density`: 音符密度倍率, 限制在 0.4 到 1.5
- `effects`: 装饰特效, 只能是 SWEEPERS, WHOOSH, ECHO, 每个乐句最多 2 个

应用只做如下处理:

- 解析 JSON, 兼容代码块, 前后说明文字与推理标签, 无法解析则丢弃整个回复并回退离线生成
- 名称不在上面的列表里, 乐句序号越界, 数值超范围的项会被忽略或限制
- SPLIT 与 SPIN 只在高难度生效, 且与上一次大动作间隔至少 3 个乐句, 简单难度会被降级
- 音符的时间始终来自本机分析, 模型只能调整密度, 判定线风格与装饰特效, 不能改变音符位置

## 失败处理

超时, 网络错误, 服务端错误, 限流会按设置重试. 鉴权失败, 请求被拒绝不重试. 最终失败时自动使用离线结果, 结果页会显示原因

## 密钥

使用 Android Keystore 中不可导出的密钥加密后保存, 不写入日志. 可在设置中清除
