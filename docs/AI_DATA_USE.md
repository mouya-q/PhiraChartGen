# AI 数据使用声明

## 默认状态

AI 增强默认关闭. 只有在设置页打开开关并明确同意后才会生效

## 会发送什么

每次生成发送一次请求 (失败时按你设置的次数重试), 内容为:

- 曲速 (BPM, 保留一位小数)
- 音频总时长 (秒)
- 按每 4 秒一段的统计: 段起点, 相对能量 (分贝), 起音数量

示例:

```
{"bpm":128.0,"durationSec":40,"segments":[{"start":0.0,"energyDb":-35.2,"onsets":0}, ...]}
```

## 不会发送什么

- 音频内容或其任何片段
- 文件名, 路径, 曲名, 艺术家, 封面
- 设备信息, 账号信息, 位置

## 发送到哪里

你在设置中填写的接口地址, 使用 OpenAI 兼容的 chat completions 接口. 请求由该服务方处理, 数据保留与使用政策由其决定, 请自行了解并确认可以接受

## 模型返回什么, 如何使用

模型返回按时间段给出的音符密度倍率. 应用只做如下处理:

- 解析 JSON, 无法解析则丢弃
- 倍率限制在 0.3 到 1.6
- 只用于调整各时间段的目标密度, 音符时间始终来自本机分析

## 失败处理

超时, 网络错误, 服务端错误, 限流会按设置重试. 鉴权失败, 请求被拒绝不重试. 最终失败时自动使用离线结果, 结果页会显示原因

## 密钥

使用 Android Keystore 中不可导出的密钥加密后保存, 不写入日志. 可在设置中清除
