# 用户手册

## 基本流程

1. 首页点击 **选择音频文件**, 在系统文件选择器中选中音乐. 也可以从其他应用分享音频到本应用
2. 选择需要的难度, 可多选
3. 选择谱面格式, 不确定时保持 RPE
4. 点击 **开始生成**, 等待分析完成, 随时可以取消
5. 在结果页查看每个难度的音符数量与类型, 点击 **预览** 试听
6. 点击 **导出** 保存单个谱面包, 或 **全部导出到文件夹**. 导出后会自动做兼容性验证
7. 在 Phira 中导入导出的 zip 文件, 步骤见 [VALIDATION.md](VALIDATION.md)

## 难度说明

| 难度 | 特点 |
| --- | --- |
| EZ | 3 条轨道, 只有点击与长按, 节奏稀疏 |
| HD | 4 条轨道, 加入少量滑动 |
| IN | 5 条轨道, 2 条判定线, 加入拖动与同时按键 |
| AT | 密度最高, 判定线摆动幅度最大 |

难度数值与等级由实际生成的谱面密度估算, 仅供参考

## 预览

- 画面按谱面真实时间与判定线运动绘制, 与导出结果一致
- 不含打击音效
- 拖动进度条可跳转, 切到后台会自动暂停

## 设置

- **音符流速**: 越大音符下落越快, 默认 10
- **网格吸附**: 音符靠近节拍网格时对齐, 现场演奏的曲目建议调小或关闭
- **谱面延迟**: 正值表示谱面更晚开始. 如果在 Phira 中发现整体偏早或偏晚, 用它校准, 写入 info.yml 的 offset
- **谱师署名**: 写入谱面包
- **玻璃模糊**: 以封面的高斯模糊为背景, Android 12 以下只压暗显示

## AI 增强

1. 设置页打开 **启用 AI 增强**, 阅读并同意数据使用声明
2. 填写 OpenAI 兼容接口地址, 模型名称与密钥
3. 点击 **测试连接**
4. 之后每次生成会请求模型给出分段密度建议. 请求失败, 超时或返回内容无法解析时, 自动使用离线结果, 结果页会提示原因

## 恢复

分析结果会缓存在本机. 如果应用在生成过程中被系统回收, 重新打开首页点击 **继续上次的曲目** 即可直接生成. 在设置页可以清理缓存

## 权限

- 文件: 通过系统文件选择器授权, 只读取你选中的文件, 不需要存储权限
- 网络: 仅 AI 增强使用
