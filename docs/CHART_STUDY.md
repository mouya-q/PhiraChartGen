# 玩家谱研究

为了让自动生成的谱面更接近真人写法, 对 10 张玩家自制的 RPE 谱面 (RPE 1.6.0 到 1.7.0, 难度约 Lv.14 到 Lv.16) 做了统计分析, 重点是判定线动画与音符布局. 谱面文件本身不在仓库中, 也没有复制其中的任何内容, 这里只记录统计结论与手法归纳

## 数据概览

| 项目 | 范围 (10 张谱面) |
| --- | --- |
| 判定线数量 | 17 到 61 |
| 音符数量 | 743 到 1844 |
| 平均音符密度 | 4.8 到 11.2 个每秒 |
| 同时按键占比 | 21% 到 62% |
| 拖动占比 | 4% 到 37% |
| 滑动占比 | 5% 到 13% |
| 长按占比 | 6% 到 32% |
| 音符落在 1/4 拍网格上的比例 | 61% 到 99% |
| 单张谱面的事件数 | 约 2000 到 14000 |

## 判定线: 主线加大量装饰线

- 最多音符的一条线承载 25% 到 83% 的音符, 前 5 条线承载 73% 到 99%
- 17% 到 60% 的线不带音符 (纯装饰), 还有不少线只带 1 个音符
- 极少使用自定义贴图, 缩放, 颜色, 文字等扩展事件, 动画几乎全部来自位置, 旋转, 透明度三类基础事件
- 少数谱面使用父子线 (父线运动带动子线)
- 主线在音符命中时刻几乎是静止的: 位置约在 (0, -250 到 -300), 旋转在 ±5 度以内

## 主线的常见手法

- **每 2 拍的倾斜**: 旋转从 0 摆到 ±3 度 (1 拍, 二次出), 回弹到反方向约 1 度 (0.625 拍, 回弹出), 再回到 0, 左右交替
- **小幅下沉**: 每 2 拍纵向下沉约 20 个单位再恢复, 对应底鼓
- **淡入淡出**: 开头淡入, 结尾淡出, 长时间没有音符的段落淡出或移出屏幕
- **整体移位**: 在过渡段把整条线平滑移到屏幕上方或外侧, 音符回来之前再还原
- **流速渐变**: 基准速度 10, 随歌曲推进小幅升高 (例如 10 到 12), 个别瞬间突增或降到 0

## 装饰线的常见手法

- **节拍闪烁扫线**: 近竖直的线 (旋转约 80 到 85 度), 每 2 拍从屏幕一侧 (约 ±600) 扫向 ±400, 左右交替, 透明度每拍脉冲一次 (0 到 120 再回 0)
- **段落开头的呼啸扫线**: 在段落开始处成对出现, 旋转约 45 度并整体移出屏幕, 持续约 1.75 拍, 下一次镜像
- **回声线**: 以主线为父线, 每 1.5 拍从主线位置向下扩散并淡出 (透明度 200 到 0)
- **高潮拆线**: 少数段落把主线拆成多条子线, 或让子线整圈旋转
- 装饰线透明度通常只有 100 到 150, 不抢音符的视觉

## 缓动

线性只占约 21% 到 75%, 其余大量使用正弦, 二次, 三次, 圆形, 回弹, 弹性等缓动. 事件很短 (中位数约 0.25 到 1 拍), 起点约 61% 到 100% 落在 1/16 拍网格上, 即动画与节拍严格对齐

## 音符布局

- 轨道位置集中在 -405, -202.5, 0, 202.5, 405 附近, 绝大部分在 ±450 以内
- 同时按键以对称或相隔约 450 单位的两个位置最常见
- 长按很短: 中位数约 0.5 拍, 90 分位约 1.4 拍
- 拖动是密集的串: 相邻间隔中位数约 1/8 拍, 单串长度中位数 4, 90 分位 16
- 音符几乎都在 1/4 或 1/8 拍网格上

## 对生成器的影响

| 改动 | 依据 |
| --- | --- |
| 主线承载约 80% 以上的音符, 位置固定在 y = -260, 去掉原来持续的扫动 | 主线在命中时几乎静止 |
| 主线每 2 拍倾斜回弹加小幅下沉, 能量高时每拍下沉 | 主线手法 |
| 新增不带音符的装饰线: 节拍闪烁扫线, 段落开头的呼啸扫线, 回声线 | 装饰线手法, 数量随难度增加 (EZ 无, HD 2, IN 6, AT 10 条上限) |
| 音符之间的长空白期主线淡出, 音符出现前淡入 | 主线手法 |
| 拆线与旋转只在高潮段偶尔出现, 并且与普通段落间隔至少 3 个乐句 | 高潮拆线 |
| 轨道改为 ±405, ±202.5, 0 (HD 为 ±405, ±135) | 轨道位置统计 |
| 目标密度 EZ 1.5, HD 3.0, IN 5.0, AT 7.5 个每秒 | 平均密度 |
| 同时按键比例 IN 18%, AT 30% (实际占比约 30% 到 46%), 优先对称位置 | 同时按键统计 |
| 长按上限 2 拍, 最短 0.5 拍或 0.25 秒 | 长按统计 |

## 未覆盖的部分

- 缓动目前只用线性, 正弦, 二次, 回弹 4 类, 弹性, 圆形等更多缓动未使用
- 父子线, 流速渐变, 整体移位尚未实现
- 音符布局只借鉴了统计特征, 没有模型化 "音高对应横向位置" 之类的创作规律
- 研究样本只有 10 张高难度谱面, 低难度写法没有参考
